🧩 Die Erstellung eines DOM-Elements planen
_____________________________________________

Objektiv:

Dient  setTimeout dazu, die Erstellung eines DOM-Elements zu planen, das eine mit Tailwind CSS gestaltete Werbebotschaft anzeigt.

Anweisungen:

Dient  setTimeout dazu, die Erstellung einer Werbenachricht nach 3 Sekunden zu planen.
Erstellen Sie ein neues DOM-Element (z. B. ein <div>  <div>) für die Werbebotschaft.
Fügen Sie der Werbebotschaft einen Text hinzu, zum Beispiel: „Sonderangebot: Sichern Sie sich 20 % Rabatt auf Ihren nächsten Einkauf!“.
Verwenden Sie Tailwind CSS, um die Nachricht mit einer Hintergrundfarbe, Innenabständen, abgerundeten Ecken und zentriertem Text zu gestalten.
Füge das neue Element dem  message-container div-Element hinzu.
